# Security policy

Photo Cut processes user-selected images locally. Security and privacy bugs that
could expose images, generated documents, purchase information or signing
credentials are treated as high priority.

Do not disclose a sensitive issue in a public GitHub issue. Contact the repository
owner privately through the GitHub profile associated with this repository.

Never commit:

- Apple certificates or provisioning profiles;
- Android keystores or passwords;
- App Store Connect or Play Console credentials;
- production purchase receipts/tokens;
- private user photographs.
