# Primary UX flow

## 1. Home / select image

Promise, privacy reassurance and one dominant “Choose photo” action.

## 2. Configure output

- width and height;
- unit selector;
- paper preset;
- copy count;
- crop-to-fill / fit-inside;
- optional advanced row for margin, gap and cut marks.

The screen should show an immediate “N copies per page / P pages” summary after
the layout engine exists.

## 3. Crop or fit

Only shown when needed. Preserve the requested physical aspect ratio. Do not show
a general-purpose editor.

## 4. Preview

PDF preview plus explicit warning:

> In the printer dialog, choose Actual size / 100%. Do not use Fit to page.

Actions: Share PDF, Print, Save/Export.

## 5. Unlock

After one successful normal export, a later export opens a concise lifetime
purchase screen. Calibration remains free.
